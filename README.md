# Windows 12 Start menu mod for Windows 11
## Introduction
This Repo is provides the JSON code for windhawk Start menu styler, windows 12 theme, I have tested this theme on a windows 11.

## Requirements
* Windhawk is installed
* Windows 11 25h2+ is require (with new start menu enabled)

## Guide
* Download Windhawk from [windhawk.net](https://windhawk.net/) and install it.
* Go to "Mods" in the upper right menu.
* Find and install the "Windows 11 Start Menu Styler" mod.
* Go to Advanced tab:

<img width="836" height="336" alt="image" src="https://github.com/user-attachments/assets/e8f3a8c5-91d1-47e4-b8a9-3ad59027820b" />

* Then scroll down to Mod settings:
<img width="699" height="177" alt="image" src="https://github.com/user-attachments/assets/51e3384c-b079-48c8-af63-72a194605846" />
